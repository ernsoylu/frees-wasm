# Determinant

Determinant


## Syntax

```
Determinant(A)
```

## Description

Determinant

## Mathematical Formulation

$$ \det(A) = \sum_{\sigma} \operatorname{sgn}(\sigma)\prod_i A_{i,\sigma(i)} = \pm\prod_i U_{ii} $$

## Input Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `A` | Number | Yes | Matrix. |
