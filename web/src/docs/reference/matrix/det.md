# det

Matrix determinant


## Syntax

```
det(A)
```

## Description

Matrix determinant

## Mathematical Formulation

$$ \det(A) = \pm\prod_i U_{ii} \quad\text{(from } PA = LU\text{)} $$

## Input Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `A` | Number | Yes | Square input matrix. |
