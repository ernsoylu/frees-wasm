# matexp

Matrix exponential


## Syntax

```
matexp(A)
```

## Description

Matrix exponential

## Mathematical Formulation

$$ e^{A} = \sum_{k=0}^{\infty} \frac{A^{k}}{k!} $$

## Input Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `A` | Number | Yes | Square input matrix. |
