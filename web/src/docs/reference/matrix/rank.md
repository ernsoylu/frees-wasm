# rank

Matrix rank


## Syntax

```
rank(A)
```

## Description

Matrix rank

## Mathematical Formulation

$$ \operatorname{rank}(A) = \#\{\sigma_i > \text{tol}\} \quad\text{(numerical, via SVD)} $$

## Input Arguments

| Argument | Type | Required | Description |
| --- | --- | --- | --- |
| `A` | Number | Yes | Square input matrix. |
